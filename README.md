# 🌟 MisiriVerse – Developer Portfolio

A modern, responsive, and animated developer portfolio built using **React**, **Vite**, and **Tailwind CSS**. It showcases my skills, projects, achievements, and professional journey as a Full Stack Developer.

---



## 🚀 Live Demo

https://misiriverse.vercel.app

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern dark-themed UI
- Smooth animations with Framer Motion
- Hero section with custom illustration
- About Me
- Technical Skills
- Professional Journey
- Featured Projects & Case Studies
- Achievements
- Contact Section
- Resume Download
- Social Links
- Smooth Scrolling

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/misiriverse.git
```

Navigate to the project:

```bash
cd misiriverse
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## 📦 Production Build

```bash
npm run build
```
